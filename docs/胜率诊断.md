# 选股胜率诊断（2026-10-16 实测，样本 201 笔）

数据：`data/signal_journal.json`，220 条记录 / 6 个交易日(20261009-20261016) / 107 只唯一票。
已结算有 ret1 的 201 笔。

## 一、踩坑雷达给出 5 行是 bug：分组键含 signal_name

`core/journal.py` `_traps()` 用 `(e["signal"], e["signal_name"])` 分组，
但 `signal_name` 是 `core/trading.py` 里的展示文案，同一 signal 会写出两种：

| signal | trading.py | name |
|---|---|---|
| B0 | `:188` | 退潮试错仓 · 首板 |
| B0 | 退潮已封板另一路 | 退潮试错仓 |
| B1 | `:283` | 首板试错 |
| W1 | `:317` | 波段第一入场点 |
| W2 | `:332` | 波段第二入场点 |
| B2 | `:410` | 龙头回踩 |

实测 B0 被拆成 "退潮试错仓" 83 笔 + "退潮试错仓 · 首板" 36 笔 → 雷达上出现两行。
修法：只用 `signal` 做键（type 是稳定契约），显示名取组内出现最多的那个。

## 二、胜率低的四个根因

### 1. 打分对次日收益零预测力（r = -0.031, n=201）
分档：60-69 胜率 35.9% / **70-79 胜率 27.9%（n=140 主体）** / 80-89 33.3% / 90-99 50%(n=6)
分信号相关：B0 +0.021、B1 +0.258、B2 **-0.355**、W1 **-0.477**、W2 -0.197
根因：`core/engine.py:1448` total=(g*wg+p*wp+i*wi)/wsum 是"审美三要素"
（好不好看），不是"明天会不会涨"；后加的封板质量/小盘弹性/涨停基因/首板加权
五个因子全是**状态描述**，每个都没有用次日收益标定过。
B0 的 score 达 112，其它信号上限 77 —— 量纲不统一，跨信号比较无意义。

### 2. 追高开是确定性的死（按 entry_gap 分组）
| 次日高开 | n | 胜率 | 均值 |
|---|---|---|---|
| 低开 < -3% | 33 | **42.4%** | **+1.18%** |
| 低开 -3~0% | 122 | 28.7% | -1.46% |
| 高开 0~3% | 36 | 30.6% | -1.64% |
| 高开 3~5% | 7 | **0%** | **-8.08%** |
| 高开 5~7% | 1 | 0% | -2.75% |
| 高开 >7% | 2 | 0% | -6.54% |

唯一正期望档是**低开**。而 trading.py 各买点 entry 文案把主要仓位押在
"高开 0~3% 先买一半"（均 -1.64%）上，3~5% 档更是 7 笔全亏。

### 3. 赔率 1.08:1 × 胜率 30% = 数学上必亏
盈利笔均 +3.85%、亏损笔均 -3.56%，期望 -1.35%/笔。
该赔率下需胜率 >48% 才不亏。stop 写"跌破买入价无条件走"（-1~2%），
但实测亏损笔均 -3.56% —— 止损承诺没兑现；盈利笔均仅 +3.85%，
止盈也没拉开。**止损没比止盈更紧**是试错仓亏损的直接来源。

### 4. 样本高度聚集，日间方差 > 信号间差异
按日期：20261009 14.3% / 20261012 **61.4%** / 20261013 **6.5%** / 20261014 38.2% / 20261015 17.9%
"某信号最近 8 笔亏 7 笔"里，**大盘当天的贡献远大于信号本身的属性**。
任何"停用信号"的结论必须先扣掉当天大盘。
