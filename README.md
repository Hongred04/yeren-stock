# 智能股票监控系统 · 野人体系

把「全能的野人」交易体系完整落地的量化选股 + 买卖点建议系统。

## 一键启动

```bash
python 启动系统.py            # 启动看板（自动开浏览器）
python 启动系统.py --report   # 只跑命令行自检报告
python 启动系统.py --port 8899
```

看板地址：<http://127.0.0.1:8777>

## 打开速度

| 场景 | 耗时 | 说明 |
|---|---|---|
| **再次打开页面** | **0.01-0.03s** | 命中结果缓存，秒开 |
| 完整重扫（K线已缓存） | ~30s | 全市场快照 10s + 情绪池历史 |
| 完整重扫（K线冷启动） | 40-80s | 首次需拉取K线 |

**打开即用**：前端先尝试读结果缓存（8秒超时保护），命中直接渲染；
未命中才启动后台任务，并**实时显示进度条 + 当前阶段 + 已耗时**（如"拉取K线 136/197… 62s"）。

三层加速：
1. **结果缓存**（3分钟 TTL）— 重复打开秒回
2. **K线内存缓存**（进程内，二级）— 二次读取 0.02s
3. **K线磁盘预载**（批量 listdir 替代 N 次 stat）— 22.9s → 0.27s，提速 85 倍

## 四套预设策略（随时切换）

| 预设 | 适用 | 关键差异 |
|---|---|---|
| **野人原版** | 缩量题材短线 | 股价5-10元、市值<100亿、权重 35/30/35 |
| **激进打板** | 情绪高位接力 | 放宽至30元/300亿，权重 25/20/55（想象力主导） |
| **保守波段** | 周期票 | 必须均线多头排列，权重 45/30/25 |
| **超短首板** | 极度聚焦 | 排除科创/北交/创业，只做主板低价 |

在看板右侧「策略配置」面板可逐项调参（阈值、权重、开关），保存后立即重新选股。

## 买卖点体系

**买入**
- B1 首板试错 — 新周期首板，回踩不破介入
- B2 龙头回踩 — 连板龙头回踩5日线，缩量企稳
- B3 缩量红盘低吸 — 极致缩量仍红盘，控盘好
- B4 尾盘博弈 — 节假日尾盘两点入场

**卖出**
- S1 退潮清仓 — 无条件清仓（最高优先级）
- S2 龙头止盈 — 五板以上分批止盈
- S3 破位止损 — 跌破10日线离场
- S4 A字杀警报 — 单日大跌立即走，绝不反包
- S5 去弱留强 — 弱于龙头则换仓
- S6 机构加速/破5日线 — 机构票专用（见 M10）
- S7 断板节奏 — 游资票专用（见 M10）
- S8 庄股回避 — 庄股不参与（见 M10）

## 主导资金分类（M10）

按主导资金给趋势分类，**离场点完全不同**；速度本身就是分类依据——
同样是五个板，游资一周走完（吃情绪溢价），机构一个月走完（吃波段收益）。

| 类型 | 量化特征 | 离场口径 |
|---|---|---|
| **机构票（中军）** | 流通 ≥80亿、近20日涨停 ≤1 次、单日最大波动 ≤7.5%、20日涨幅 5~60%、多站5日线 | 小阳线爬五日线、进二退一，波段持有 2~4 周；**离场信号 = 加速**——慢牛突然拉涨停（哪怕一个）= 出货冲顶，立刻减仓；破5日线先减半 |
| **游资票（龙头）** | 近10日涨停 ≥2 次或当前 ≥2 连板 | 连板/断板节奏，两板一断、两板一断；离场跟着断板节奏走——断板日盯回封，**断板2天不回封 = 节奏破坏，撤** |
| **庄股** | 低波动阴跌/横盘（日均 ≤2.8%、无涨停）后近10日出现 ≤-7% 断崖大阴 | **不参与**。做庄失败打回原点，盈亏比极差；持仓遇断崖无条件出 |

系统对每只候选股自动分类（选股表徽标 + 详情页「主导资金」面板），
买入建议按类型拦截（庄股直接「不参与」），卖出建议按类型追加 S6/S7/S8。

## 题材主线五信号（M9）

一条题材主线行情的成立，需要 5 个信号**按时间顺序依次共振，缺一环就是「一日游」**：

| # | 信号 | 系统怎么判 | 缺环后果 |
|---|---|---|---|
| S1 | **消息定级别** | 默认**自动定级**：抓取 7x24 快讯（新浪财经直播→同花顺→东财快讯降级），关键词规则分级（国家战略S→部委政策A→行业事件B→个股公告C），只统计与主题材相关的快讯；面板手动录入优先 | C 级或消息不够大 → 直接按一日游，后面都不用看 |
| S2 | **首日看合力** | 涨停池按题材聚类：题材内同日涨停 ≥3 家且开盘 60 分钟内封板 ≥2 家，板块指数带量创 60 日新高 | 无合力 = 资金没集体行动，孤军奋战就是一日游 |
| S3 | **中军定容量** | 题材板块成分股里流通 ≥100 亿的大票是否异动（涨幅 ≥3%） | 无中军 = 游资脉冲，当天冲高就结束 |
| S4 | **老龙是前兆** | 本地「老龙档案」（历史 ≥3 连板个股）今日是否有异动（≥5%） | 引信未点燃 → 降级观察 |
| S5 | **次日定生死** | 昨日涨停池 → 今日开盘：空间龙候选平均高开 ≥3%、首板活口留存 ≥50%、中军最弱不破 -2% | 次日检验不过 = 主线地位不成立 |

四种结论：**主线成立 / 首日启动·待次日验证 / 信号不全·仅观察 / 一日游特征·回避接力**，
结论联动 M8 纪律体检（一日游 → 黄色提醒「题材内不接力」）。

**数据口径与冷启动**：题材以涨停池行业板块为代理；板块指数/成分股走东财行业板块接口，
取不到时降级为「未验证」不硬性否决；昨日涨停池与老龙档案由本地
`data/pool_history/` 逐日归档积累（每天第一次扫描自动存档），刚启用前几天 S4/S5 显示
「积累中/待验证」属正常。

## 关键风控设计

退潮判定需**同时满足**「亏钱面积 ≥ 阈值」+「至少一条结构信号」，避免单日节前效应被误判为周期退潮。退潮/极度缩量时，名单标记为「观察储备」，不给出买入建议。

## 数据源

| 用途 | 接口 | 说明 |
|---|---|---|
| 实时快照 | 腾讯 qt.gtimg.cn | 60只/请求，全市场6000+只约10秒 |
| 日K线 | 腾讯 ifzq.gtimg.cn → 新浪兜底 | 双源自动降级 |
| 涨停/跌停/炸板池 | 东财 push2ex | 含连板数、题材、封板时间 |
| 指数 | 腾讯 | 两市成交额测算量能模式 |

> 注意：东财池接口忽略 date 入参，真实交易日以响应体 `data.qdate` 为准，节假日会自动回退到节前最后交易日。

## 项目结构

```
stockmon/
├── 启动系统.py          # 一键启动
├── selfcheck.py         # 命令行自检报告
├── server.py            # HTTP 服务（纯标准库）
├── core/
│   ├── universe.py      # 全市场代码枚举
│   ├── datasource.py    # 数据引擎（多源降级 + 三层缓存）
│   ├── indicators.py    # 技术指标与形态识别
│   ├── engine.py        # 策略引擎（M1-M8 判定 + M10 分类挂载）
│   ├── trading.py       # 买卖点 + 仓位链（S6/S7/S8 类型化离场）
│   ├── mainline.py      # M9 题材主线五信号（消息/合力/中军/老龙/次日）
│   ├── news.py          # M9-S1 自动消息定级（多源快讯抓取 + 关键词分级）
│   ├── fundstyle.py     # M10 主导资金分类（机构/游资/庄股 + 速度）
│   ├── pipeline.py      # 分析管线编排（带进度回调）
│   └── strategy_config.py  # 策略配置与预设
├── web/index.html       # 看板前端
├── data/strategy.json   # 当前策略配置
├── data/zt_history.json # 涨停家数曲线（本地累积）
├── data/pool_history/   # 每日涨停池快照归档（M9 次日验证/老龙档案）
└── cache/kline/         # K线缓存（内存二级 + 磁盘，12小时）
```

## API

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/result` | GET | 取结果（优先缓存，秒回） |
| `/api/start` | GET | 启动后台分析，**立即返回** |
| `/api/status` | GET | 轮询进度 `{pct, progress, elapsed, running, done}` |
| `/api/invalidate` | POST | 使结果缓存失效 |
| `/api/config` | GET/POST | 读取/保存策略配置 |
| `/api/preset` | POST | 切换策略预设 |

## 风险提示

本系统为量化工具输出，所有评分、买卖点、仓位建议均为模型计算结果，**不构成投资建议**。市场有风险，决策需自负。保住本金是第一原则，交易唯有自渡。
