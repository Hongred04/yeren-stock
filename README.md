# 智能股票监控系统 · 野人体系

把「野人体系」那套打法拆成能跑的规则：扫一遍全市场，给出候选股、买卖点和仓位建议。
纯本地运行，数据取自公开行情接口。

## 一键启动

```bash
python launcher.py            # 启动看板（自动开浏览器）
python launcher.py --report   # 只跑命令行自检报告
python launcher.py --port 8899
```

Windows 双击 `start.bat` 也行。看板地址：<http://127.0.0.1:8777>

重扫一次约 30s（K线已缓存），冷启动 40-80s。重复打开页面走结果缓存，0.01-0.03s 秒开。

## 看板导航

5 个一级板块，各挂二级页面，一次看一页。当前页记在 localStorage，刷新后停在原处。

| 一级 | 二级页面 | 看什么 |
|---|---|---|
| 今日总览 | 今日结论 · 仓位计划 | 一句话结论 + 三问速览 + 明日判断；该拿多少仓位 + 5 步推演 |
| 市场情绪 | 情绪温度计 · 题材主线 · 涨停梯队 | 0-100 温度 + 连板梯队；五信号判题材持续性 + 板块强弱；涨停池明细 |
| 资金动向 | 资金在干什么 | 游资/机构/北向动向 + 主力主攻/撤离方向 |
| 选股决策 | 候选股票 · 信号胜率 | 打分清单 → 点开个股详情；历史信号 1/3/5 日复盘 |
| 我的持仓 | 持仓体检 · 自选观察 | 复用卖出信号给持仓体检；自选股只盯不做 |

一级菜单带角标（情绪温度、候选股数、体检告警数）。点涨停池/持仓/自选里的股票会弹出详情。

### 个股详情

不只限当天候选股 —— 点任意一只票都会按代码向后端要一份 `/api/stock?code=xxx`
（现拉快照 + 70 根 K 线），用与候选股完全相同的口径重新打分，
弹出右侧面板，分「决策 / 依据 / 行情」三个页签。

## 决策链（与原体系一一对应）

| 环节 | 输出 |
|---|---|
| 宏观背景 | 利率/汇率周期定位 |
| 量能模式 | 全市场成交额分级，判"钱够不够" |
| 情绪阶段 | 主升 / 发酵 / 分歧 / 退潮 |
| 题材主线 | 五信号判持续性 |
| 连板结构 | 高度、梯队完整性 |
| 选股 | 三要素打分（图形 · 价市值 · 想象力） |
| 仓位 | 分级仓位建议 |
| 纪律 | 风控清单 |

## 策略：单套「野人体系」（自适应）

只有一套策略，按市场阶段自动调节松紧，不手动切档。
参数在右侧「调策略」面板里改，写入 `data/strategy.json`。

## 扩展模块

| 模块 | 内容 |
|---|---|
| E1 情绪温度计 | 连板梯队/炸板率/晋级率/赚钱效应/涨跌家数 → 0-100 温度曲线 |
| E2 龙虎榜席位 | 每日上榜股 + 营业部席位（机构/北向/知名游资识别），只出结论 |
| E3 主力资金流 | 行业板块与个股主力净流入 |
| E4 信号胜率 | 历史信号 1/3/5 日复盘闭环 |
| E5 低位承接 | 机构兑现的钱可能去哪 |
| E6 停牌·补位推演 | 龙头停牌了，同题材里谁在接棒 |
| E7 逆势连板 | 谁的连板不是情绪撑的（产业逻辑候选） |
| E8 题材播种 | 事件→受益→标的，前置题材池 |
| E9 竞价早读 | 集合竞价高开分布 + 昨涨停池竞价状态 |

## 买卖点体系

买点按可用时机分档，涨停日屏蔽当日买入建议：

- **首板 / 回踩均线 / 突破平台 / 缩量回调** 等，各带触发条件与失效位
- 卖点分三档：退潮清仓 / 机构加速 / 断板
- 任何一只票的买卖点都带止损位与仓位建议

主导资金分四类（M10），用持仓与离场口径区分；题材主线用五信号（M9）判持续性。

## 关键风控设计

- 缺数据不出结论：指标取不到显示「—」，绝不写死百分比冒充读数
- 涨停日不推当日买点，避免"推荐打不进去的板"
- 退潮期降级为试错仓（0.5 成），不接力、不重仓
- 纪律体检 10 条，冲突时在结论卡显式告警

## 数据源

| 源 | 用途 |
|---|---|
| 腾讯快照 | 全市场实时行情（主行情源） |
| 东财 push2 | 资金流、板块（clist 主链路，ulist.np 备用） |
| 通达信 TDX | 指数日 K |
| 同花顺 / 财联社 | 板块资金流降级链、题材事件 |
| 央视新闻 / 部委 | 消息面 |

所有源的实时状态与接口熔断在「数据源」面板里可见。取不到数据时按源逐级降级，
并在报告里如实写明来源。

### 排查：取不到行情 / 找不到这只股票

1. 打开右上角「数据源」面板看各源状态
2. 点「解除封锁」/「重连」重置熔断
3. 仍不行就跑 `python selfcheck.py` 看是哪一环断的

## 项目结构

```
core/           策略引擎
  datasource.py   数据源（行情/资金流/板块/消息）
  engine.py       决策链主流程
  pipeline.py     扫描管线
  sentiment_meter.py  情绪温度计 (E1)
  cls.py          财联社/同花顺源
  rebound.py      低位承接 (E5)
  substitute.py   停牌补位 (E6)
  industry.py     逆势连板 (E7)
  sowing.py       题材播种 (E8)
  auction.py      竞价早读 (E9)
  outlook.py      次日预案
  indicators.py   技术指标
  journal.py      信号胜率 (E4)
  strategy_config.py  策略参数
  version.py      版本号（唯一出处）
web/
  index.html      桌面看板
  mobile.html     手机端（独立文件，不共用桌面样式）
data/           运行时数据（大部分不入库）
tests/          测试

launcher.py     启动入口
selfcheck.py    命令行自检报告
```

## API

| 接口 | 说明 |
|---|---|
| `GET /api/result` | 最近一次扫描结果 |
| `POST /api/refresh` | 触发后台重扫 |
| `GET /api/status` | 扫描进度 |
| `GET /api/stock?code=` | 单只股票详情 |
| `GET /api/kline?code=` | K线数据 |
| `GET /api/config` · `POST /api/config` | 读/写策略配置 |
| `GET /api/portfolio` · `POST /api/portfolio` | 持仓自选读写 |

## 安卓 App

`android/` 下是 WebView 壳，打包产物在 `dist/`（不入库）。
`build_exe.bat` 打 Windows 单文件 exe。

## 风险提示
