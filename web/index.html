东财按「请求量 + IP 信誉」双重风控。系统的对策是主动限流，不被动挨打： ① 每分钟只给它 15 次请求额度，超了就不发（改走备用源，不触发风控）； ② 万一被掐，冷却封顶 4 分钟，每 60 秒半开探测，东财一恢复就自己回来； ③ 被掐期间板块资金改走财联社（同样有主力净额）、涨跌家数改走开盘红， 最后才退新浪 —— 界面始终标注数据来自哪家； ④ 你开着 Clash 时，系统自动借它的节点出口（换干净 IP —— 家宽 IP 被标记 时这招最有效），Clash 没开则自动直连，都不用你操作。
关于滑块：那是东财网页对被标记 IP 的人工验证，程序绕不过。要更新 Cookie： 点下面按钮在浏览器完成滑块 → F12 → 网络(Network) → 随便一个请求 → 请求头里复制 Cookie 值 → 粘贴到上面保存。
